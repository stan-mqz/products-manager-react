# Products Client Application

## 🌐 English

### Description
This is a modern React-based client application built with TypeScript and Vite. It provides a user-friendly interface with features including:
- React 19 with TypeScript support
- Vite for fast development and building
- React Router for navigation
- Axios for API communication
- Valibot for form validation
- TailwindCSS for styling
- ESLint for code quality

### Installation
1. Make sure you have Node.js installed on your system
2. Clone the repository
3. Navigate to the client directory:
   ```bash
   cd client
   ```
4. Install dependencies:
   ```bash
   npm install
   ```

### Available Scripts
- `npm run dev`: Start the development server
- `npm run build`: Build the application for production


### Development
To start the development server:
```bash
npm run dev
```

The application will start on the default Vite port (usually 5173).
